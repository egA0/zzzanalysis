# 抽卡规划台

离线优先、无账号接入的《绝区零》限定角色/音擎规划网页。基础概率、综合概率、硬保底与限定分支已通过 HoYoverse 官方概率 JSON 核验；默认逐抽软保底曲线采用可独立回滚的第三方拟合模型。核验与风险见 [docs/SOURCES.md](docs/SOURCES.md)，字段级回滚见 [docs/RULE-CHANGELOG.md](docs/RULE-CHANGELOG.md)。

## 目录结构

- `../成品/`：项目根目录中的构建产物，可直接部署。
- 当前目录（项目根目录中的 `工程文件/`）：源代码、配置、文档和开发依赖；开发与检查命令均在此目录执行。

## 快速开始

Node.js 20.19+ 或 22.12+：

```bash
cd 工程文件
npm ci
npm run dev
```

打开开发服务输出的本地地址。数据通过 IndexedDB 保存在当前浏览器；安装 PWA 后可离线使用。版本时间轴只保留本地内置的官方卡池记录，不再实时联网搜索；未来版本根据官方公告手动写入卡池记录，复刻周期表与复刻预测仍由本地卡池记录实时生成。“版本资源”页面分别手工填写活动页面菲林/抽数与已获得菲林/抽数，并按版本持续时间计算每日活跃和月卡资源；未来版本资源固定按每版本 90 抽推演。所有资料来源链接和引用统一在“数据来源”页查看。

## 检查与发布

```bash
npm run typecheck
npm run lint
npm run format:check
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run test:pwa
npm run verify:rules
```

`verify:rules` 直接读取 HoYoverse 当前限定角色/复刻角色/音擎/复刻音擎概率 JSON，与本地官方基线比较；发现差异时失败，但不会自动改写规则。

卡池记录内置 1.0 至 3.2 的本地官方记录。时间轴不再调用 BannerHistory、BWIKI 或英文日期源；未来版本更新通过手动新增/修改记录完成，并保留批次回滚能力。全角色复刻周期表由卡池记录实时生成，因此写入新一期后，上期角色会自动开始离池计时；预测候选会覆盖完整的未来版本序列；界面默认展示概率最高的几个候选版本。目标编辑的名称输入带完整角色/音擎下拉目录，选择角色后自动套用最高概率版本。官方已公布但未实装的角色资料可在时间轴补充并随来源回滚。

`../成品/` 是静态站点构建输出。Cloudflare Pages：在 `工程文件/` 执行构建命令 `npm run build`，发布目录为项目根目录下的 `成品`。GitHub Pages：当前 GitHub Actions 工作流位于 `.github/workflows/pages.yml`；由于工作流文件归档在 `工程文件/` 内，若要启用自动发布，需按 GitHub 要求将其放到仓库根目录的 `.github/workflows/`；Vite `base: './'` 支持仓库子路径。部署在 HTTPS 下 PWA 才可安装。不要把用户的导出 JSON 提交到公开仓库。

## 技术与范围

React、严格 TypeScript、Vite、Zustand、IndexedDB、ECharts、Vitest、Playwright、Web Worker、PWA。样式使用项目内 CSS 而非 Tailwind：第一版以概率正确性与静态部署为先，保持依赖和设计令牌简单；可后续迁移 Tailwind。
`src/i18n` 提供简体中文词条入口与未来语言回退结构；完整多语言文案尚未上线。

普通限定与特殊复映频道使用互不读写的状态。独家重映/音擎回响有单独概率页和可撤销来源补丁；普通限定的 S 级信号自选只改变歪出候选对象。常驻频道不纳入规划。收入默认全关闭，未来资源累计默认开启，现实货币预算默认关闭且不折算抽数。资源页支持记录信号余波、信号残响等抽卡副产物并按兑换门槛折算抽数；设置页可按账号重复率填写每抽副产物均值，模拟会在抽取过程中即时兑换为后续预算，精确状态转移仍使用不含未来返还的保守资源线。规划消耗分位数含失败停止，**不等于成功保障线**。
