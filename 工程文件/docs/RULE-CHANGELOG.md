# 抽卡规则变更与回滚记录

核验日期：2026-09-16。

## 2026-09-22 资源与时间轴改为离线手工基线

- 默认模拟次数改为 1000；新建数据默认开启未来资源累计，旧数据保留用户已有开关选择。
- 版本资源页删除联网奖励抓取，改为手工填写活动页面版本资源与本版本获取度，并按版本持续时间计算每日活跃与月卡资源。
- 活动页面资源与本版本已获得资源均拆分为菲林、抽数两项输入；资料来源链接与引用集中移至“数据来源”页。
- 未来版本资源不再从历史第三方样本估算，固定按每版本 90 抽推演。
- 版本时间轴删除实时联网卡池搜索，仅保留本地官方记录；未来卡池通过手工记录更新，复刻周期表与复刻预测继续基于 `data.banners` 工作。
- 旧版数据会迁移到新的手工资源字段；变更前快照由项目外层 `回滚备份_变更前_2026-09-22.zip` 保留，可恢复此次改动前的源代码与成品。

## 官方基线

角色限定频道采用官方公开的基础 S 概率 0.600%、90 抽硬保底、S 为当期限定概率 50.000%、歪后下一 S 为当期限定、S 综合概率 1.600%、限定 S 综合概率 1.067%。音擎频道采用基础 S 概率 1.000%、80 抽硬保底、S 为当期限定概率 75.000%、歪后下一 S 为当期限定、S 综合概率 2.000%、限定 S 综合概率 1.600%。

官方 3.2 公告明确：所有角色限定频道之间的保底计数累计，所有音擎频道之间的保底计数累计，两类频道彼此独立。官方概率详情没有逐抽披露软保底曲线，也没有在当前正文中单独解释切换不同限定目标后“歪后保证状态”的继承。

## 软保底建模

GachaData 明确说明其角色曲线不是官方逐抽表，而是从第 74 抽开始的线性曲线，并拟合官方 1.600% 综合概率；其公开参数为 `softInc = 0.052992`。音擎模型采用 ZZZ Database 社区样本所示第 65 抽起点，再以相同线性拟合方法反推每抽增幅约 `0.055208`，使模型综合概率匹配官方 2.000%。这两组阶梯都属于可撤销模型。

## 特殊频道状态机

特殊频道使用 `first-s-selected-v1` 状态机，分别保存垫数、特殊频道常规歪后保证、当期首次 S 特殊保证、折扣可用状态和当前自选目标。普通限定状态不会被读入或写回。切换同一期目标只更换目标名；载入新一期时，特殊保证与折扣恢复，垫数和常规保证按当前来源补丁决定保留或重置。

## 2026-09-16 卡池历史与联网更新

- 补齐 1.0 至 3.2 的角色、音擎和 2.5/3.1 特殊频道记录，并为每条记录保存版本、期数、来源类型和稳定键。
- 新增 ZZZBuild 在线检查：自动检查、差异预览、确认写入、缓存回退、来源结构失效提示和更新批次回滚。
- 新增全角色复刻周期表，自动显示历史登场、相邻登场间隔、当前/已公布状态和离池天数。
- 卡池来源链调整为 BannerHistory 简中日程优先、绝区零 BWIKI 校对中文名，ZZZBuild 仅作日期回退；官方记录覆盖同键第三方记录。
- 3.1 特殊频道误写角色已更正为“琉音”，非当期限定结果的描述统一为“歪”。

第三方内容拆成两个回滚单元：拒绝 ZZZ Wiki 只改变跨期垫数；拒绝 BitTopup 会关闭特殊概率推断并重置跨期常规保证。恢复“仅官方规则”会保留用户输入，但不再展示缺少概率依据的计算结果。

## 2026-09-17 版本资源与版本目标改造

- 目标编辑由手工停止日期改为“目标版本 + 第 1/2 期”，停止日期由卡池记录或未来版本预测自动计算。
- 资源收入独立为侧边栏“版本资源”页面；保留原时间轴中的旧收入条目以兼容既有数据，但规划收入会在启用估算时叠加版本资源预测。
- 新增当前版本游戏内累计获取度输入，并按 160 菲林 = 1 抽比较已获取、剩余和整版估算。
- 新增 U7BUY、3DM、Game8 版本资源来源单元；来源按来源 ID 独立停用并回滚，缓存与内置值不覆盖用户资源输入。
- 当前版本多来源数值不一致时，展示范围并默认采用较低值作为保守规划基线；官方字段与第三方整版总量分开。
- `schemaVersion` 升至 7；旧数据中的手工目标日期迁移为 3.2 第 2 期，避免丢失已有截止日期信息仅作兼容。

## 2026-09-18 目标角色目录与未来版本预测

- 目标名称改为带 `datalist` 的角色/音擎目录：目录由所有已收录卡池记录和用户补充的已公布立绘角色合并生成。保留文本输入以兼容旧的自定义目标。
- 选中目录角色后自动填入最高概率的复刻/实装版本和期数；目标编辑中展示概率最高的候选版本及概率，但候选计算不再限制为当前版本后的 3 个版本；目标版本支持直接输入任意未来版本号。
- 版本时间轴的复刻周期表新增“未来预测”列，并对尚未实装的未来首期显示“预计实装”。
- 删除时间轴内的“资源收入”页签；独立“版本资源”页面和收入计算逻辑保留，避免影响已有规划数据。
- 未取得可稳定交叉核验的新增官方立绘名单时不静默补入角色；通过时间轴表单手动添加的资料可逐条删除回滚。

## 2026-09-18 未来版本边界与资源累计

- 取消“只预测当前版本后 3 个版本”的限制；目标版本使用可输入的版本号字段，并提供未来版本 datalist 建议。
- 版本序列在跨大版本时参考历史大版本的小版本数量。当前数据中 1.x 有 8 个小版本、2.x 有 9 个小版本，因此 3.x 预测到边界后会切换到 4.0。
- 版本资源预测按目标截止日期累计：当前版本剩余资源、完整结束的未来版本资源、以及目标日期所在版本按时间比例取得的资源都会进入可用抽数；仍遵守“将估算收入计入可用资源”开关。
