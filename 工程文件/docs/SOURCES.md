## 特殊频道建模边界

- “独家重映”和“音擎回响”使用独立状态机；垫数和常规歪后保证均不与普通角色/音擎限定频道互通。
- 同一期切换自选目标时，垫数、常规保证、当期特殊保证和十连折扣状态都保留。
- 新一期恢复首次 S 特殊保证和首十连折扣。跨期垫数及常规歪后保证目前分别依赖 ZZZ Wiki、BitTopup 可撤销补丁。
- 特殊频道逐抽 S 曲线复用当前对应角色/音擎模型，因此 GachaData 或 ZZZ Database 软保底补丁的开关也会同步影响特殊频道。
- 普通限定频道的“S 级信号自选”只影响歪出对象，不改变获得当期限定目标的概率，不另建保底。
- 未知未来机制不会自动套用本模型；只有明确声明为 `first-s-selected-v1` 的频道才可计算。

## 仍缺少的内容

1. 官方逐抽软保底概率表，包括准确起点、每抽增幅以及是否为线性变化。
2. 官方明确说明歪后的限定保证在切换到另一个同类型限定目标后是否继承。
3. 官方明确说明独家重映/音擎回响的垫数及常规歪后保证是否跨不同版本的特殊期继承。
4. 游戏内中文“详情”页面的当前完整截图或文字导出，用于与官方英文 JSON 交叉校验。

在这些内容得到官方材料前，应用会同时展示官方综合概率与当前模型综合概率，便于发现模型偏差。
